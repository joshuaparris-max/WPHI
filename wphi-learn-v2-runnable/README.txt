WPHI LEARN V2 — HOW TO OPEN IT

WINDOWS
1. Extract the ZIP file.
2. Double-click OPEN-WPHI-LEARN.bat.
   Or double-click index.html.

MAC
1. Extract the ZIP file.
2. Double-click index.html.

LINUX
1. Extract the ZIP file.
2. Double-click index.html or run open-wphi-learn.command.

IMPORTANT
- Keep index.html and app.js in the same folder.
- The first load requires internet access because React is loaded from unpkg.com.
- This is an interactive front-end prototype, not a production student system.
- Demo progress is stored locally in your browser.
- Clearing browser site data may reset the demo.
